# MIXDTX-COMPSKIN

Repo skin KOMPRESOR untuk APK MIXDTX/MIXJOS (tab KOMPRESOR di pemilih skin).
URL index: `https://raw.githubusercontent.com/siapagatau/MIXDTX-COMPSKIN/master/index.json` (diatur di `assets/config/comp-skin-repo.json`).

- `PROMPT_SKIN_KOMPRESOR.md` — aturan membuat skin kompresor.
- `skins/comp-dbx234/` — skin satu unit rack pipih (rasio asli dbx 234), viewBox 1280x118.
- `gen.py` membuat skin, `validate.py` memeriksanya; setelah mengubah skin, jalankan `gen.py`, `validate.py`, lalu hitung ulang `index.json` (sha256 + size).

Upload isi folder ini ke root repo GitHub `MIXDTX-COMPSKIN` (branch master).
